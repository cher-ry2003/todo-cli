# Todo CLI

A command-line task manager in pure Python: add tasks with due dates and priorities, mark them complete, update descriptions, and review completed history — all managed through a clean `ToDoList` class.

## Features

- Add tasks with optional due date and priority
- Complete, update, and remove tasks by ID
- Separate views for active and completed tasks

## Run it

```bash
python main.py
```

Standard library only — no dependencies.
